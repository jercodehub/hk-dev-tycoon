# HK Dev Tycoon

香港發展商模擬，Phase 3。一局 **20 個項目**。每一個項目係：揀地 → 起樓 → 售樓 → 資金回籠 → 一則短故事。

**娛樂模擬，非投資意見。** Entertainment simulation, not investment advice.

畫面只留決策：現金、聲譽、市況（辣／鬆）、項目 n/20、下一步。售樓再加飯碗同客池剩餘。唔顯示開放數據來源、唔重複經濟標語、唔顯示舊存檔重置提示。

## 點玩

`fetch` 讀唔到 `file://`。喺倉庫根目錄開靜態伺服器：

```bash
python3 -m http.server 8080
```

然後開 <http://localhost:8080/> 。

- 成立公司：打主席名，揀圓形頭像，再改公司名、標誌同顏色。局中只可以喺 HUD 頭像或者選單「集團同主席」改。
- 每個項目三幅地，或者唔買：**地皮 A / B / C / 唔買（下次再投）**。地皮有口語區味（近大學、偏遠上車、核心／豪區），同埋貴、平、合理。
- 政府推地**無分成**，多數喺新市鎮。市建局一定喺成熟市區，有分成。地鐵有分成，鐵路交通會加高賣出機會。
- 起樓用 + − 分配五種戶型（開房 280 呎、一房 350、兩房 450、三房 600、特色戶 1000）。剩餘可建面積唔夠就加唔到。可以一撳 開房／上車／換樓／豪宅。每行有受歡迎程度（高／中／低）。預計成本呎價只出一次，放喺可建面積旁邊。確認前有區味提示同預期銷情區間；精確「預計沽出 n%」留喺售樓處。
- 市況每三個項目翻一次。鬆：大手同開房旺，可能有西餅客一次掃 2–3 伙。辣：上車同自住相對穩，投資客縮。
- 起樓畫面嘅項目名可以撳「改名」。預設跟區同區味，例如深水埗·偏遠上車。售樓處都可以改。
- 售樓前先揀賣平、合理、賣貴（約 0.82／1.00／1.18）。每個叫價顯示售價呎價、兩房叫價，同「薄利易清／平衡／慢清利厚」。畫面有一個打氣之前嘅「預計沽出 n%」，五條戶型 bar 用同一個模型，改價、回佣、廣告、示範單位會即時郁。打氣前亦見到建築費、宣傳費（回佣＋廣告＋示範單位）同預計賺幾多倍；打氣後見到實際多賺幾多。
- 回佣無／普通／大，廣告只可以打一個客群（收租／上車／換樓／特色），預算少或多。打錯客，錢照使，嗰條 bar 唔會升。售樓打氣途中唔改廣告。
- 售樓顯示客池剩餘、兩房飯碗（食得起／兩房食唔起）。飯碗裂只係兩房高過上車預算。示範單位要錢。打氣要撳完先至結算。真係賣晒先叫沽清；仲有貨先至減價清。賣唔晒可以減價清，或者留貨凍住現金。凍結金額同仲有幾多個項目先解凍會出喺 HUD，解凍時現金會跳。
- 若果爛尾，跳過「起緊樓」之後一定先揀「趕工補救」定「接受差啲銷情」，先至入售樓處。承建商卡上嘅報價同結算原報價係同一個數。結算比較原報價同承接之後嘅數。
- 今次項目嘅口碑留喺售樓同結算。揀地 HUD 用累積街坊口碑，兩邊唔撈。賣晒唔會叫「貴而無貨」。HUD 可以打開項目紀錄：開價、沽清／部分／流標、承建商、爛尾。
- 項目之間有「地產香港」短選，會加減聲譽、現金，偶爾郁一個客池。
- 進度寫入呢部瀏覽器嘅 LocalStorage（`hk-dev-tycoon-v3`，存檔版本 7。版本 3、4、5、6 會就地升級，唔會清檔）。
- 承建商有可比嘅漏水／爛尾條。爛尾之後可以揀趕工補救，或者接受差啲銷情。結算仍然比較原報價同承接之後嘅數。
- 開售直接見到「上一個類似盤」嘅叫價同結果，唔使先打開一行標題。
- 確認起樓之後有一段可跳過嘅「起緊樓」。售樓處係同一塊決策畫面。
- 每個項目喺起樓先揀自資／借少少／借大數。借貸寫明借幾多、利息、到期還幾多，而且只計你嗰一份。自資意思係現金夠付自己嗰份；唔夠就講明仲差幾多，唔會無聲透支。資金回籠先還。還到息同部分本金可以續玩。第一次未還係黃牌（寫明未還幾多，下一幅地細啲）。結算同時寫結餘現金同尚欠。連續兩個項目未還先至今局完。遊戲內借貸，非借貸意見。
- 地盤由細開始，淨資產夠先至解鎖中、大、旗艦。一萬伙以上只會出現喺後期旗艦，而且唔係每一個後期項目都變大。一鋪爛尾或者借大數唔會永遠鎖死萬伙。大地盤用大級距或比例預設，銷情按分座計，數字用千／萬。
- 中盤或以上、又冇市建／地鐵分成嘅地，揀地時可以揀全資或者合營 25%／35%／50%。細地盤維持全資。合營只付嗰一份地價、建築、宣傳、趕工同另覓承接，亦只收嗰一份收益。25% 只係降低入場現金，唔會解鎖更大嘅地盤。借貸其後先揀，而且只按你嗰一份計。遊戲內聯營，娛樂模擬，非投資意見。

## 測試

```bash
npm test
```

`node --test` 覆蓋戶型 GFA、客池消耗、辣／鬆、區味、飯碗、示範單位、餘貨、西餅客、政府地無分成、故事加減、20 個項目，同畫面唔輸出已禁用標籤。Phase 1 季度引擎仍然喺 `game/engine.js`，測試照跑，頁面已經唔再用季度時鐘。

## 更新校準數據

要網絡。會重抓差餉署 CSV 同屋宇署樓宇資料，再寫入 `data/market-stats.json` 同 `data/parcels.json`。呢啲檔只做內部校準，畫面唔顯示來源標籤。

```bash
python3 scripts/refresh_data.py
```

已有本機檔就可以唔下載：

```bash
python3 scripts/refresh_data.py \
  --buildings /path/to/buildings.json \
  --stock-csv /path/to/district-stock.csv \
  --prices-csv /path/to/1.2M.csv \
  --index-csv /path/to/1.4M.csv
```

`scripts/build_market_stats.py` 若果平均售價出現 18 區鍵，會拒絕寫出。

## 數據來源

- 屋宇署樓宇資料及樓齡紀錄，`hk-bd-opendata-building-information`。地圖唔係揀地。
- 差餉物業估價署物業市場統計，`hk-rvd-tsinfo_rvd-property-market-statistics`。樓價只用全港指數同三區平均售價做內部比例。

倍率喺 `game/campaign-balance.json`。

## 布局

- `index.html` — 靜態頁
- `game/campaign.js` — 20 個項目嘅純函數，無 DOM

- `data/market-stats.json` — 內部校準
- `test/campaign.test.js`、`test/phase3.test.js`、`test/midterm.test.js`、`test/nextpack.test.js`、`test/economy.test.js`
